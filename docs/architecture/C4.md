## 2. Container View (C4Container)

```mermaid
C4Container
  title Container Diagram: UpstreamDrift Core Subsystems

  Person(user, "Researcher / Coach", "User of desktop GUIs, web dashboards, or Python modeling APIs.")

  Container_Boundary(c1, "UpstreamDrift Platform") {
    Container(launchers, "Desktop & Web Launchers", "Python 3.11+, PyQt6, Tauri/React", "Unified launcher hub, model explorer, simulation dashboards, and tile registry.")
    Container(physics_adapters, "Physics Engine Adapters", "Python 3.11+, MuJoCo, Drake, Pinocchio, OpenSim", "Pluggable engine adapters evaluating forward dynamics, inverse dynamics, and constraint jacobians.")
    Container(motion_pipeline, "Motion Capture & Pose Pipeline", "Python 3.11+, OpenCV, MediaPipe", "Multi-camera video calibration, synchronization, markerless keypoint extraction, and C3D kinematics.")
    Container(biomech_analytics, "Biomechanics & Analytics Engine", "Python 3.11+, NumPy, SciPy, CasADi", "Kinematic sequencing, ground reaction forces, drift-control decomposition, X-Factor, and energy metrics.")
    Container(optimal_control, "Trajectory Optimization & OCP", "Python 3.11+, Bioptim, CasADi", "Direct collocation, shooting solvers, and parameter identification for human swing motions.")
    Container(api_service, "REST & WebSocket API", "Python 3.11+, FastAPI, Uvicorn", "Endpoints for simulation control, telemetry streaming, tile discovery, and dataset export.")
  }

  System_Ext(tools, "Tools Platform", "Shared signal and model generation libraries.")
  System_Ext(engines, "Physics Runtimes", "MuJoCo, Drake, Pinocchio, OpenSim.")
  System_Ext(hardware, "Cameras & Hardware", "High-speed and web cameras.")

  Rel(user, launchers, "Launches tools, inspects 3D scenes, and controls runs via", "PyQt6 / Web")
  Rel(launchers, physics_adapters, "Drives simulation execution through", "Engine Interface")
  Rel(launchers, motion_pipeline, "Triggers calibration and video tracking in", "Python API")
  Rel(launchers, api_service, "Communicates with background services over", "HTTP / WebSocket")
  Rel(physics_adapters, engines, "Binds to", "Native C++ / Python Bindings")
  Rel(motion_pipeline, hardware, "Captures raw frames from", "Camera Drivers")
  Rel(physics_adapters, biomech_analytics, "Streams joint kinematics and contact forces to", "In-Memory Arrays")
  Rel(optimal_control, physics_adapters, "Evaluates dynamics constraints via", "Symbolic / Numerical Backend")
  Rel(biomech_analytics, tools, "Consumes signal filters and rotational algebra from", "Python Package")
```

## Feature Map

| Capability                                 | Component                                                                                 | Interface                       | Evidence                                                             |
| ------------------------------------------ | ----------------------------------------------------------------------------------------- | ------------------------------- | -------------------------------------------------------------------- |
| Multi-Engine Physics Simulation & Parity   | Physics Engine Adapters (`src/engines/physics_engines/`)                                  | Python Engine Protocol          | `tests/engines/`, `tests/test_cross_engine_parity.py`                |
| Markerless Motion Capture & Reconstruction | Motion Pipeline (`src/motion_capture/`, `src/tools/capture_rig/`)                         | Python Pipeline API / CLI       | `tests/motion_capture/reconstruct/`, `tests/tools/capture_rig/`      |
| Biomechanics & Kinematic Metrics           | Biomechanics Analytics (`src/shared/python/biomechanics/`, `src/shared/python/analysis/`) | Python API / Analysis Functions | `tests/shared/python/biomechanics/`, `tests/shared/python/analysis/` |
| Trajectory Optimization & Optimal Control  | Trajectory Optimization (`src/shared/python/optimization/ocp/`)                           | CasADi / Bioptim OCP API        | `tests/shared/python/optimization/`                                  |
| Desktop & Web Tile Launchers               | Launchers & Web UI (`src/launchers/`, `ui/`)                                              | PyQt6 GUI / React Tauri App     | `tests/launchers/`, `tests/tools/`                                   |
| Simulation Telemetry & Service API         | REST & WebSocket API (`src/api/`)                                                         | FastAPI / WebSocket Endpoints   | `tests/api/`                                                         |
