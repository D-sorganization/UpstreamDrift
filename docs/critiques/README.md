# Critique Index

Adversarial scientific reviews of UpstreamDrift claims, produced by the Fleet
Critic role ahead of the Friday Board Meeting packet.

## Methodology

Reviews focus on logical gaps, unstated assumptions, empirical insufficiency,
overgeneralization, and literature conflicts — not code quality. Each session
targets the last 30 days of changes plus persistent documented claims. Findings
are classified Low / Medium / High severity. High findings are flagged to the
Board.

Assigned seat: **Bravo (fleet-critic)**
Cadence: Bi-weekly, 1st and 3rd Friday.
