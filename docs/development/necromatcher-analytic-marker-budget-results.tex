\textbf{Measurement Scopes.} SciPy 1.16.0 reports \code{nfev} and \code{njev}; these are backend counters, not a count of every internal finite-difference residual call. Solver time covers the backend invocation. Worker time covers child entry through computed payload or caught failure, excluding imports, telemetry publication and final transport serialization. Neither is parent polling time. Earlier records lack comparable authenticated timings, so no measured speedup is claimed.
