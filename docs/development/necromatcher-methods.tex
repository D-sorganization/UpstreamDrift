\reportsection{Scope, Evidence Classes, and Success Criteria}

\subsection{What the Current Workflow Provides}
Necromatcher creates a persistent player and swing library, imports immutable
capture versions, reviews original source frames with observations, binds saved
native models to research fits, and exports a portable swing package. Web and
native presenters consume shared storage and fitting boundaries. Source-stamped
refit jobs preserve request options, cancellation state, outcomes, and rejection
reasons. A reusable implementation therefore extends beyond a pair of player
scripts: an additional historical figure uses the same acquisition, admission,
review, model binding, and job procedure.

The present technical work has produced real image-constrained MuJoCo hypotheses
for both players. Their residuals are computed from the original observations;
their native models are compiled resources. The hypotheses remain rejected
research because the clock, anatomy, closed continuous motion, and historical
control recovery have not met acceptance. Computational completion and scientific
qualification are deliberately separate fields.

Saving an artifact never promotes its evidence class. A checksum proves identity,
not correctness. Native compilation proves that an engine can load a model,
not that the model represents the golfer. A small pixel residual proves neither
anatomical plausibility nor usable grip closure.

\subsection{Concrete Acceptance for a Future Player}
The repeatable delivery must retain original evidence; reproduce a bound native
candidate from explicit assumptions; review image residuals at fitting and
held-out frames; satisfy authored ranges and usable closure throughout a
continuous motion; and independently replay the controls with mixed units,
unactuated root, contact, and refinement diagnostics. Simulation, impact, and
whole-analysis consumers must preserve these identities and qualification.
AffineDrift publication is a separate integration and source-rights decision.
The current report does not claim those remaining stages complete.

\subsection{Presentation Time Is Not Physical Time}
For each decoded frame, retain the integer PTS $p_i$ and rational time base
$a/b$, giving source presentation time
\begin{equation}t_i^{\mathrm{src}}=p_i\frac{a}{b}.\end{equation}
The exact tuple belongs to the original frame identity. Do not replace it with
the rounded slider label, a generated frame number divided by nominal fps,
or a newly remuxed clip's assumed broadcast offset. Keyframe preroll and
stream-copy boundaries can alter the relation between clip and original time.

A physical clock requires a separately justified mapping
$t^{\mathrm{phys}}=f(t^{\mathrm{src}})$. Slow motion, duplicate frames,
telecine, edits, and unknown playback scale make $f(t)=t$ an assumption.
The current captures retain unknown physical time. Even if a local mapping were
affine, $t^{\mathrm{phys}}=\alpha t^{\mathrm{src}}+\beta$, source-clock
velocities and accelerations would scale by $1/\alpha$ and $1/\alpha^2$.
Physical effort identification therefore cannot ignore this unknown scale.

Download one authorized source at a time with \code{yt-dlp}, retaining metadata,
format identifiers, title/uploader, acquisition version, and complete asset hash.
Prefer bounded official archive windows when they reduce transfer and review
cost. Decode the selected half-open interval using the existing capture CLI;
retain increasing rational PTS, original observation JSONL, and lossless PNGs.
Record detector and implementation hashes. Review continuity, identity, camera
changes, and duplicate source lineage before selecting a fit window.

Raw media stays outside Git. The capture archive contains its evidence, so
subsequent recall does not require the original Downloads path. Import checks
source identity, normalized observation validity, frame order, interval,
dimensions, counts, decoded image hashes, and observation-byte hashes.
Unknown rights and \code{publication_permitted=false} remain explicit.

\reportsection{Image Observations, Native Geometry, and Camera Hypotheses}
\subsection{Image Coordinates and Missingness}
MediaPipe 1.0.1 uses the full pose model, with smoothing disabled and detection
and tracking thresholds of 0.5. The archived output remains image inference.
The fit associates thirteen image landmarks with assumed native attachments:
nose, both shoulders, elbows, wrists, hips, knees, and ankles. These attachment
positions are generic anatomy assumptions, not calibrated skin markers.

For normalized landmark $(x_{ij},y_{ij})$ and image dimensions $(W,H)$, the
pixel target is
\[\mathbf u_{ij}=(W x_{ij},H y_{ij})^T.\]
Missing observations
have zero objective weight and null reported error. Unknown visibility is not
silently known visibility: the experiments explicitly use weight 0.5 for that
case. Recorded visibility is used as an objective weight where present; it is
not a calibrated probability of anatomical accuracy.

\subsection{One Generic Resource and Explicit Ordered Units}
The actual generic driver resource compiles to 44 scalar coordinates: three
translations in metres and 41 rotations in radians. Coordinates are ordered by
the compiled native binding, with named hinge/slide types used to verify units.
Model import alone does not prove this native ordering. Resource validation
checks the immutable model/fit/capture bindings and reproduces compiled XML from
its generic definition.

Thirty-two coordinates have explicit authored angular ranges. Twelve remain
unbounded: root translations and rotations, and both three-axis shoulder
coordinates. Authored ranges are converted from degrees to radians only after
checking named compiled angular units. They constrain this research experiment;
they are not measured Tiger or Hogan range-of-motion limits.

\subsection{Camera Model and Conditional Initialization}
Let $\mathbf X_j(\mathbf q)$ be the native world position of attachment $j$,
and let $R\in SO(3)$ and $\mathbf t\in\R^3$ map world points to camera points.
With intrinsic matrix $K$, prediction is
\begin{equation}
 \mathbf x_c=R\mathbf X_j(\mathbf q)+\mathbf t,
 \qquad \widehat{\mathbf u}_j=\pi(K\mathbf x_c),\quad
 \pi([v_1,v_2,v_3]^T)=[v_1/v_3,v_2/v_3]^T.
\end{equation}
Positive depth, proper orthonormal rotation, finite inputs, positive focal
lengths, and a homogeneous intrinsic bottom row are validated.

The first research initialization assumes focal lengths equal to image width,
principal point at image centre, and zero distortion. OpenCV SQPnP followed by
LM refinement uses at least six nondegenerate correspondences, conditional on
an authored address seed and generic geometry. This obtains an initial camera
hypothesis. It is not an independently calibrated camera. Monocular depth,
scale, geometry, camera orientation, and joint pose can trade off while
retaining similar pixels; the report keeps those ambiguities separate from
detector evidence.

\reportsection{Spline MAP Fitting and Source-Stamped Jobs}
\subsection{Objective and Native Derivatives}
Free native coordinates are represented with the shared cubic Hermite spline;
locked coordinates retain the supplied seed. For coefficients $\mathbf c$ and
source time $t_i$, let $\mathbf q_i=\mathbf q(t_i;\mathbf c)$ and
$\mathbf v_i=d\mathbf q/dt^{\mathrm{src}}$. The implemented residual stack is
\begin{equation}\label{eq:map}
\mathbf r(\mathbf c)=
\begin{bmatrix}
 \{\sqrt{w_{ij}}(\widehat{\mathbf u}_{ij}-\mathbf u_{ij})\}_{i,j}\\
 \{\lambda_p D^{-1}(\mathbf q_i-\mathbf q_0)\}_i\\
 \{\lambda_s T D_f^{-1}\mathbf v_{i,f}\}_i\\
 \{\lambda_g\mathbf g(\mathbf q_i)\}_i
\end{bmatrix},\qquad
\min_{\mathbf c}\tfrac12\|\mathbf r(\mathbf c)\|_2^2.
\end{equation}
$D$ contains explicit native coordinate scales, $f$ denotes free coordinates,
$T$ is the selected source duration, and $\mathbf g$ is the native positional
grip-separation residual. Weights shown in Equation~\ref{eq:map} multiply
residuals, so their squared values weight squared costs. Source derivatives
are not physical velocities. The original image spline objective does not
include the later finite orientation repair or hard anatomical bounds.

Native frame-pose derivatives use the canonical central-difference helper;
the estimator then applies exact spline basis derivatives. This avoids
recomputing a native derivative for every coefficient perturbation. The method
reuses the existing shared MAP estimator rather than maintaining a second
optimization framework. The original estimator leaves trajectory coefficients
unbounded; fitting a low image residual can therefore produce implausible
coordinates or open grip geometry.

\subsection{Opt-In Interior Constraints and Scalar Spline Assessment}
The source \code{b92732e725} adds explicit \code{ConstraintOptions} to the
historical spline fit while preserving the original position-only closure
behavior when those options are absent. The public native IK capability
returns six grip rows---three world position components in metres and three
principal world rotation-log components in radians---followed by one row for
each declared ground-contact sphere. Every row is dimensionless:
\begin{equation}
 r_k(\mathbf q)=\frac{\sqrt{w_k}}{s_k}\,g_k(\mathbf q),
 \qquad w_k\geq0,\quad s_k>0.
\end{equation}
Position and ground scales use metres; rotation scales use radians. These
weights differ from the residual multipliers in Equation~\ref{eq:map}:
$w_k$ weights the squared native discrepancy after scaling. Zero-weight and
inactive ground rows retain their ordered identities. Unpinned ground rows
measure penetration only; explicitly pinned spheres retain signed depth.
Ground, pinning, scales, and weights are authored assumptions.

For spline knots $\tau_k$ and explicit increasing fractions
$\alpha\in(0,1)$, the constraint evaluation set is the sorted unique union
\begin{equation}
 \mathcal T=\{t_i^{\mathrm{src}}\}_i\ \cup\
 \{\tau_k+\alpha(\tau_{k+1}-\tau_k)\}_{k,\alpha}.
\end{equation}
Only original source rows enter the image, pose-prior, and speed residuals,
landmark RMS, observed counts, and missingness reports. An interior evaluation
is a constraint probe; it adds no decoded frame, observation, confidence,
or source-frame identity. The public native Jacobian $J_q(t)$ is chained
through the canonical free-coordinate spline basis $B_f(t)$:
\begin{equation}
 \frac{\partial\mathbf r_{\mathrm{constraint}}(t)}{\partial\mathbf c}
 =J_{q,f}(t)B_f(t),\qquad t\in\mathcal T.
\end{equation}
The existing MAP estimator consumes these rows; no separate solver or native
geometry implementation is introduced. Saved assessments retain tested times,
stable row labels, scaled residuals, and their maximum absolute value. A finite
probe set can miss an intervening nonlinear grip or ground failure. Principal
rotation logs also have a branch discontinuity at $\pi$, and penetration-only
contact has a derivative kink at zero depth. The report therefore retains
\code{continuous_certified=false}.

A separate scalar-coordinate assessment checks the preserved cubic Hermite
trajectory over its full source interval. For normalized segment time
$u\in[0,1]$, write $q(u)=a u^3+b u^2+c u+d$. Candidate extrema comprise both
endpoints and the real interior roots of $3a u^2+2b u+c=0$. Candidate values
are evaluated through the canonical spline API, retaining extrema, source
times, and lower/upper violations in each coordinate's native units. Locked
coordinates must remain constant. Stored source poses must agree with the
preserved spline under absolute tolerance $10^{-10}$ and relative tolerance
$10^{-8}$ before this assessment is admitted. Named authored limits must be
finite and two-sided with lower $\leq$ upper; equal limits are supported.
Unbounded coordinates remain explicitly unbounded. This floating-point scalar
assessment neither enforces hard bounds during fitting nor certifies nonlinear
closure/contact, physical timing, dynamics, or historical motion.

\subsection{Canonical Hard Hermite Coordinate Bounds}
A subsequent tested implementation at source \code{73ace83145} adds
\code{HermiteBoundsDomain} to the canonical single-trial MAP estimator. The V7 artifacts below
were produced at \code{b92732e725} without this domain and retain their original
rejected outcomes; the new feature does not retroactively repair those paths.

For a segment of duration $h$, the scalar cubic Bernstein controls are
\begin{equation}
 b_0=q_0,\quad b_1=q_0+\frac{h v_0}{3},\quad
 b_2=q_1-\frac{h v_1}{3},\quad b_3=q_1.
\end{equation}
Keeping all four controls in a named finite coordinate interval $[L,U]$
keeps the entire scalar segment in that interval by the convex-hull property.
This is a sufficient conservative domain: some bounded cubics have Bernstein
controls outside their limits and are excluded. It constrains model
coordinates in their declared native units; it supplies no nonlinear grip,
contact, camera, anatomical, physical-clock or dynamics qualification.

A bounded knot position $q$ supplies outgoing and incoming admissible
source-clock velocity intervals
\begin{equation}
 I_{\rm out}=\left[\frac{3(L-q)}{h_{\rm out}},
                         \frac{3(U-q)}{h_{\rm out}}\right],\qquad
 I_{\rm in}=\left[\frac{3(q-U)}{h_{\rm in}},
                        \frac{3(q-L)}{h_{\rm in}}\right].
\end{equation}
Interior knots intersect both intervals, with $\ell$ the largest lower
endpoint and $u$ the smallest upper endpoint. End knots use their sole
incident segment. A normalized decision $w\in[-1,1]$ decodes as
\begin{equation}
 \theta=(w+1)/2,\qquad v=(1-\theta)\ell+\theta u.
\end{equation}
Each knot has one shared decoded velocity, preserving $C^1$ continuity on
nonuniform knot grids. Equal coordinate limits remove their decision columns
and decode to constant position $L$ and zero velocity. Unbounded coordinates
retain ordinary physical position and velocity decisions.

The adapter strictly encodes a feasible physical initialization. It rejects
infeasible positions or Bernstein controls, nonzero fixed velocities, and
unsupported/nonrepresentable limits; the public historical-fit binding also
rejects unknown names and inconsistent locked seeds. Neither boundary clips
output or silently repairs an existing candidate. A caller
may explicitly author a feasible initialization with bounded positions and
zero slopes, recording that assumption. A collapsed velocity interval encodes
zero velocity with $w=0$; other normalized decisions can decode to the same
zero there.

The decoder Jacobian $D$ maps internal decisions to the ordinary physical
Hermite coefficients. Away from branch ties,
$\partial v/\partial w=(u-\ell)/2$ and
$\partial v/\partial q=(1-\theta)\ell'+\theta u'$. At exact active-branch
ties it returns the mean active slopes as a symmetric generalized derivative;
one-sided derivatives can differ. No proximity tolerance changes the domain,
and this kink treatment does not imply optimizer convergence.

Physical callback layouts and saved coefficients retain the canonical spline
contract. For physical coefficient Jacobian $J_c$ and shared-parameter
Jacobian $J_p$, the internal Jacobian is $[J_cD,\,J_p]$; shared prior rows,
parameter locks, and identifiability gates retain their own columns and
semantics. Finite internal bounds select the existing trust-region solver
when necessary. An entirely fixed problem evaluates its objective without
calling SciPy on zero decisions. Multi-trial MAP rejects this single-trial
capability explicitly. No second fitting solver is introduced.

\code{ImageFitConfig.coordinate_bounds} supplies immutable named
$(\text{name},L,U)$ records, transported through its narrow JSON decoder.
Unspecified coordinates remain unbounded; no bounds keeps the original
identity coefficient domain. The checked public procedure is
\path{docs/development/necromatcher-hermite-bounds.md}.
The V8 receipts below now record historical bounded trials and their image
tradeoffs. Their separate scalar-bound and nonlinear audits must not be
confused with a historical execution claim for the earlier V7 artifacts.

\subsection{Exact Native Authored Range Provenance}
\code{NativeFitBinding.authored_coordinate_bounds()} derives ranges from the
immutable definition bytes captured by the loader. These are the exact JSON
serialization bytes already used to export and compile the binding, not a
later serialization of mutable fit metadata or a replacement definition.
The public MJCF exporter must reproduce the binding's exact XML hash before
any ranges are admitted. The two identities remain distinct:
\begin{equation}
 \begin{aligned}
 H_{\rm def}&=\mathrm{SHA256}(\text{captured definition bytes}),\\
 H_{\rm XML}&=\mathrm{SHA256}(\text{exported XML UTF-8 bytes}).
 \end{aligned}
\end{equation}
A definition hash identifies that loader serialization; it does not claim
identity with an original external JSON file. A matching XML hash binds the
reproduced native resource, not historical anatomical correctness.

The captured coordinate order must match the compiled public native order.
Every exported coordinate must be a named scalar hinge or slide whose type
agrees with the independently compiled units. Authored
\code{coordinate_ranges_deg} entries may name only known hinges with radian
units. Finite ordered degree limits convert in that same native order as
\begin{equation}
 [L_j,U_j]_{\rm rad}=\frac{\pi}{180}[L_j,U_j]_{\rm deg}.
\end{equation}
Unknown names, translation-coordinate degree ranges, malformed endpoints,
unit/order mismatches, or failure to reproduce the exact XML are errors.
Undeclared coordinates remain explicitly unbounded; no fallback limit is
invented. The detached immutable result retains named bounds, ordered
unbounded names, both hashes, and
\code{range_source=bound_native_definition.coordinate_ranges_deg}.

Every scalar joint in this export has \code{limited="false"}; the extractor verifies that
declaration and records \code{compiled_limits_enforced=false}. The authored numeric ranges are
not compiled MuJoCo limits. Their enforcement belongs to the explicit optimizer coefficient
domain. They remain model hypotheses rather than measured Tiger/Hogan range of motion.
Extraction reuses public binding/export contracts without private SDK state or another native

\subsection{Explicit Authored Feasible Initialization}
The default \code{ImageFitConfig.initialization_policy="strict"} continues to
reject an infeasible starting spline. The explicit alternative,
\code{authored_range_project_zero_slopes}, changes only a newly authored
optimizer initialization. It is not a repair or clipping of a finished fitted
output. Named bounds are required, and locked native seed coordinates outside
those bounds remain errors.

Let $q_{kj}^{\rm old}$ and $v_{kj}^{\rm old}$ be the canonical free-coordinate
knot positions and source-clock slopes before initialization. Exactly once,
for each bounded free coordinate, the public initializer sets
\begin{equation}
 q_{kj}^{\rm init}=\min\!\left(U_j,
                   \max\!\left(L_j,q_{kj}^{\rm old}\right)\right),\qquad
 v_{kj}^{\rm init}=0.
\end{equation}
Unbounded free positions remain unchanged, but \emph{all} free knot slopes
become zero, including those of unbounded coordinates. Equal limits produce
constant position and zero slope. This is an explicit modeling choice; zero
slopes are not velocities inferred from footage. With zero slopes, each
segment's Bernstein controls reduce to its two endpoint positions, so bounded
endpoints supply a feasible conservative start. The public
\code{domain.encode(initialized_coefficients)} call verifies that feasibility
as a postcondition rather than applying another correction.

The pure initializer copies its inputs and calls no optimizer or native engine. The image-fit
integration retains the original observations, confidence, missingness, source identities and
\mbox{\code{ImageFitInputs.seed}}. Consequently, the pose-prior target remains the original seed; it
is not silently replaced by projected knots. \code{initial_rms_pixels} measures the actual
initialized spline against the original image evidence, with the original confidence-weighted
landmark denominator. A prior sample RMS must not be substituted for this initialized baseline.

A reproducible authoring sequence is:
\begin{enumerate}
\item Load the exact fit/model/capture binding; retain original parents and
verify the captured definition, exported XML, native order and compiled units.
\item Extract declared authored bounds and explicit unbounded names; reject
locked-coordinate conflicts. Construct the canonical free-coordinate domain.
\item Construct the original physical Hermite coefficients from the selected
source samples and knot clock. Explicitly select the authored policy and apply
one position projection plus zero slopes.
\item Verify \code{domain.encode}; retain the original/initialized coefficient
hashes, per-knot changes, per-coordinate position displacements, units and clock.
\item Evaluate the initialized spline against unchanged source observations.
Publish a new source-bound research seed only with these identities and fresh
metrics; run optimization separately when explicitly requested.
\end{enumerate}

\subsection{Exact Preserved Hermite Restart and Recipe Transport}
\label{sec:preserved-restart}
A saved native image fit can now supply an explicit physical Hermite start to
\code{fit_image_spline}. This is a reproducibility capability, separate from
numerical acceptance of a golfer. The operation has two disclosed choices:
\emph{Sample Parent Poses} retains the existing reconstruction of new knot
positions and slopes from selected parent samples; \emph{Resume Saved Spline}
loads the parent's declared canonical coefficients and original knot clock.
The latter performs no sample-to-knot interpolation, authored position
projection, or slope reset. Legacy parents without a preserved spline are
reported as unavailable; malformed declared identities are rejected rather
than replaced by a sampled start.

\paragraph{The Bound Coefficient Identity.}
The immutable public \code{ImageSplineStart} record contains six fields:
\code{knot_times}, \code{spline_coefficients}, \code{coordinate_order},
\code{free_coordinates}, \code{model_sha}, and \code{coefficient_sha256}.
For $K$ knots and $n_f$ free coordinates, its finite canonical coefficient
vector has length $2K n_f$ and retains the shared trajectory's packing order
for knot positions and source-clock slopes. Let $\operatorname{LE64}(\mathbf c)$
be the contiguous little-endian IEEE~754 binary64 bytes of that vector, in
its declared order. Its coefficient identity is
\begin{equation}
 H_c=\operatorname{SHA256}\!\left(\operatorname{LE64}(\mathbf c)\right).
\end{equation}
The serialized value carries the \code{sha256:} prefix. This hash identifies
coefficient bytes; it does not by itself bind the knot clock, coordinate
names, model, parent, or observations. Those remain explicit validated fields
and immutable fit/model/capture hashes. Initial and final physical snapshots
are retained independently: \code{initial_spline} records the admitted start,
\code{initial_coefficient_sha256} exposes its coefficient hash, and
\code{spline_start} records the returned final coefficients for a later
restart. The snapshots do not imply that an optimizer ran or converged.

\paragraph{Strict Preconditions.}
The preserved path requires \code{operation="fit"},
\code{initialization_source="preserved_spline"}, and
\code{initialization_policy="strict"}. The native model identity, ordered
full and free coordinate names, explicit knot grid and knot count must agree.
Knot times must be finite and strictly increasing, and the requested evidence
must span exactly the saved first and last source times. The worker evaluates
the canonical preserved trajectory at the parent's source timestamps and
checks the stored parent poses against it using absolute tolerance $10^{-10}$
and relative tolerance $10^{-8}$. Locked coordinates retain the parent's
first pose. Any authored hard-bound domain must admit the unchanged physical
start; an infeasible start fails rather than being projected or clipped.
These checks preserve the full source interval and reject a shortened window
or a silently replaced spline. Optimizer transformations and subsequent
floating-point evaluation remain subject to their recorded numerical checks;
a coefficient identity is not a claim of exact arithmetic or nonlinear
constraint satisfaction.

\paragraph{Evidence and Prior Semantics.}
Within each job, decoded observed pixels, source-frame identities, confidence
weights, the camera hypothesis, and the pose prior remain fixed for the
admitted request. Optimizing coefficients changes predicted pixels, not the
observations. Every new job uses its selected parent's first source pose as
its pose-prior reference, including an exact spline restart. Consequently an
identical coefficient start does not establish an identical objective across
jobs: the parent/prior identity, selected image rows, weights, and full recipe
must also be compared. Source-clock slopes remain derivatives with respect
to container presentation time, not measured physical velocities.

\paragraph{Complete Recipe Transport in Both Interfaces.}
Native and web controls expose the initialization choice explicitly. The
refit plan supplies \code{baseline_config}, preferring the preserved original
fit configuration, and a \code{preserved_spline} descriptor containing
availability, reason, original knot count, and source interval. A saved
restart uses that clock, requires both interval endpoint frames, and submits
strict initialization. The complete request \code{config} remains nested:
iteration budget, prior/smoothness/closure weights, named coordinate bounds,
interior fractions, initialization policy, and native grip/ground options
are retained together. The latter include the ground plane, position and
rotation weights/scales, penetration scale, and explicitly pinned sphere
identities. A brief range/pin summary discloses retained authored hypotheses;
heel pinning remains an unobserved operator assumption, not measured contact.
Legacy scalar requests remain supported when no nested configuration is
provided; an ambiguous nested/scalar mixture is rejected. Visibility weight,
coordinate scales, source indices, wall budget, operation, new version ID,
and initialization source retain their separate request fields.

\subsection{Authored Contact Phases on the Source Clock}
\label{sec:contact-phases}
A constant whole-track heel pin can conflict with visible release and later
unobservable feet. The canonical phase boundary therefore records an authored
contact hypothesis rather than promoting a shoe silhouette to measured
contact. It reuses the existing native constraint provider and MAP estimator;
no separate geometry, contact solver, or force inference is introduced.

\paragraph{Typed Schedule, Binding, and Resolution.}
\code{ContactPinPhase} contains rational \code{start_pts} and \code{end_pts},
immutable named \code{pinned_spheres}, and immutable
\code{review_frame_sha256} references. \code{ContactPinSchedule} binds its
ordered phases to \code{capture_id}, \code{capture_sha256}, and
\code{status="authored_contact_hypothesis"}. Rational pairs have integer
numerators and positive integer denominators. Phases increase and cover the
complete fitted interval without gaps or overlap. The interval convention is
$[t_k,t_{k+1})$, with the final schedule endpoint included; a shared boundary
belongs to its following phase.

The workspace binder runs before optimization against the hash-verified
parent and original capture. It validates capture identity, source asset,
shot, swing, and camera identifiers; each rational boundary must resolve to
one exact original frame PTS. Every reviewed decoded-frame hash must resolve
to one frame in its phase's boundary-inclusive evidence interval; this review
convention is separate from half-open pin selection. Wrong-phase or ambiguous repeated-image
references fail. Schedule hashes use the \code{sha256:} prefix; the existing
capture's bare decoded-frame hashes are normalized for comparison. These
hashes identify decoded image content and must not be replaced with the
different PNG-byte hashes. Matching stored camera identifiers does not
calibrate the changing source framing.

\code{ScheduledConstraintOptions} wraps existing \code{ConstraintOptions}
in \code{base} and \code{schedule}; the eight-field \code{ImageFitConfig}
retains this complete nested wrapper. At each evaluation time,
\code{resolve} copies the base with the active named pin set and calls the
same public native residual/Jacobian method. Native row identities and
dimensions remain fixed, including released and inactive ground rows.
Recipe recall and scalar edits must retain the wrapper, not flatten away its
phase or evidence identities. A legacy unscheduled configuration preserves
its former semantics.

\paragraph{Normal Height Is Not No-Slip Contact.}
For declared sphere $s$, let $h_s(\mathbf q)$ be its signed normal height
relative to the authored ground plane and $P(t)$ the active pin set. Its
scaled ground row is
\begin{equation}
 r_s(\mathbf q,t)=\frac{\sqrt{w_g}}{s_g}
 \begin{cases}
 h_s(\mathbf q),&s\in P(t),\\
 \min\{0,h_s(\mathbf q)\},&s\notin P(t).
 \end{cases}
\end{equation}
Pinning targets zero normal height; releasing a sphere retains the unilateral
penetration penalty, even in an unknown phase whose equality-pin set is empty.
Neither case anchors tangential position, enforces no-slip velocity, specifies
a toe pivot, identifies friction, or measures ground reaction force. The
sphere geometry, plane, weights, scales, and selected pin identities remain
model assumptions. Ground-height agreement alone cannot qualify contact.

\paragraph{Exact Boundaries and Separate Floating-Point Probes.}
Phase endpoints retain exact rational source identities, and their floating
representations must remain distinct. The canonical objective includes source
times, configured interior probes, and phase boundaries in its constraint
assessment. It adds no image observation, confidence, or physical timestamp.
The independent audit also evaluates both representable one-sided neighbors
\code{nextafter(t,-infinity)} and \code{nextafter(t,+infinity)} where they lie
inside the fitted interval. Those are numerical probes of phase selection;
they are not rational decoded-frame timestamps or a measured time before or
after heel release. Their labels and active pins remain distinct from exact
boundary records. Source frames, rational adjacent-frame midpoints, and
canonical scalar extrema remain in the audit. Neither finite probing nor
one-sided branch checks certify continuous nonlinear motion.

\reportsection{Finite Rotation Closure and Bounded Native Repair}
\subsection{Why the Former Rotation Residual Failed}
Let $R_a,R_b$ denote grip-site world rotations and $E=R_aR_b^T$ their relative
rotation. The previous small-angle residual was
\begin{equation}
 \mathbf r_{\sin}=\tfrac12\operatorname{vee}(E-E^T)
 =\sin\theta\,\mathbf n.
\end{equation}
It falsely vanishes at a half turn. The native MuJoCo implementation now uses
the principal logarithm, computed with SciPy \code{Rotation.as_rotvec}:
\begin{equation}\boldsymbol\phi=\operatorname{Log}(E)^\vee
 =\theta\mathbf n,\quad 0\leq\theta\leq\pi.\end{equation}
Its norm correctly reports $\pi$ at reversal. The principal logarithm still
has an inherent branch discontinuity at a half turn; local correctness does
not prove global convergence. Shared/Drake legacy rotation semantics remain
unchanged by this native-only repair.

\subsection{Exact Local Logarithm Derivative}
If $J_a,J_b$ map native coordinate variations to world angular velocities,
the left perturbation of $E$ is $J_a-EJ_b$. The residual derivative is
\begin{align}
 \frac{\partial\boldsymbol\phi}{\partial\mathbf q}
 &=J_l^{-1}(\boldsymbol\phi)(J_a-EJ_b),\\
 J_l^{-1}(\boldsymbol\phi)
 &=I-\tfrac12\skewmat{\boldsymbol\phi}
 +\left(\frac{1-(\theta/2)\cot(\theta/2)}{\theta^2}\right)
 \skewmat{\boldsymbol\phi}^{\,2}.
\end{align}
The implementation uses the stable small-angle coefficient
$1/12+\theta^2/720$ near zero. Multiplying only $J_a-J_b$ was an
infinitesimal approximation and failed finite-angle derivative tests.
Central differences at two non-small native poses validate the implemented
derivative with absolute tolerance $2\times10^{-7}$ and relative tolerance
$2\times10^{-6}$. The half-turn regression verifies nonzero reversal error.

\subsection{Opt-In Trust-Region Reflective Solver}
The existing LM loop computes an unconstrained normal-equation step and clips
it to bounds. This can stagnate at active bounds. Native callers may now use
\code{SolvePoseOptions(solver="trf")}. The default LM behavior remains.
TRF reuses preparation, residual/Jacobian stacking, and final diagnostics; only
free coordinates enter SciPy \code{least_squares}, with finite or infinite
authored bounds and \code{x_scale="jac"}. Paired residual/Jacobian evaluations
at the same free vector share native FK results.

Locked coordinates remain exact. A locked value outside its bound, nonfinite
lock, unknown solver, or unsupported provider fails. All-locked requests
evaluate once without invoking SciPy. Native ground penalties have fixed row
count: inactive unpinned contacts contribute zero residual and zero derivative;
pinned contacts retain signed height. This preserves the old objective while
preventing dimension changes inside TRF. Providers without fixed-row support
reject the opt-in path.

An active-bound seed initially exposed a false cost-only convergence: SciPy's
tiny first trust-region step returned approximately $2\times10^{-10}$ instead
of the bounded optimum 1 in the synthetic regression. Opt-in \code{ftol=None}
prevents that cost-only early stop; existing step/gradient criteria and the
evaluation cap remain. TRF's reported budget is residual evaluations
(\code{nfev}), while default LM reports loop iterations. Neither budget
exhaustion nor a solver success flag establishes scientific acceptance.

\subsection{Interpreting the Video Overlay}
Review the original PNG and detector landmarks beside native attachment
projections at the same exact frame identity. Mark image observations and
model projections distinctly; show missingness, source PTS, unknown physical
time, and research qualification. A shared overlay avoids renderer-specific
coordinate conversion. Selecting a new frame hides stale imagery/projections
while its request is loading, so asynchronous completion cannot paint the
previous frame over the new one.

High residuals can indicate camera, correspondence, generic geometry, pose,
occlusion, or detector errors; they are not automatically evidence of a
particular anatomical defect. Low residuals can conceal open grips,
inter-frame branch jumps, or wrong depth. The review must therefore include
grip/ground/range plots, worst frames, and observed-foot visibility, rather than
accepting visual similarity alone.

Windows Qt/native projection uses a clean serialized SDK subprocess because
native plugin initialization failed in a Qt-parent thread/spawn context.
The worker verifies resource and source identities; timeout/cancellation
terminates only its owned process. This boundary is shared infrastructure,
not a second geometry or inference implementation.

\subsection{Run Checklist for an Additional Historical Player}
\begin{enumerate}
\item Check issue ownership and post an appropriate lease. Use an isolated
topic worktree; read local policy and shared-infrastructure boundaries.
\item Catalog source URLs, owner-provided files, footage lineage, source dates,
rights, metadata, format identifiers, and exact file hashes. Review identity
and continuity before choosing a bounded capture window.
\item Extract original frames and observations with exact PTS; retain detector
weights/version, implementation hash, lossless frame hashes, and missingness.
\item Import through the checked capture API; reopen the archive and verify
frame identities and source images before numerical work.
\item Bind an immutable native resource to that swing, verifying exact compiled
coordinates/units and all needed model resources. Document geometry and
camera assumptions before fitting.
\item Create a new source-stamped research fit using explicit samples, knots,
scales, weights, budgets, and visibility prior. Preserve originals; inspect
training, held-out, and dense residuals plus model/video overlays.
\item If placement is revised, create a separate authored version and apply
camera compensation. Verify image invariance and all-frame ground diagnostics.
\item Repair bounds and closed motion; measure source-image tradeoffs. Audit
all samples and intermediate motion, not only anchor or fitting frames.
\item Author controls only with explicit clock/units/provenance, preserve an
unactuated root, then perform fresh-resource replay and refinement.
\item Export through checked swing packaging. Admit downstream simulation,
impact, and analysis only when their exact capability and evidence gates hold.
\end{enumerate}
