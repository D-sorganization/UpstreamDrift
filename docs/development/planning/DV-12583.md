# DV-12583: NSX-55 Golf-Model Simscape Closed-Loop Export in MATLAB R2025b

Source: [UpstreamDrift#12583](https://github.com/D-sorganization/UpstreamDrift/issues/12583) (Parent Epic: [UpstreamDrift#12593](https://github.com/D-sorganization/UpstreamDrift/issues/12593)). Status: **deferred**. Board: **pending**.
Disposition: **split**. Kind: research-idea.

## Rationale and Expected Value

The Simscape closed-loop snapshot needs `M`, `h`, `J_c` and `Jdot_v` of the golf model
at given states, taken from MATLAB R2025b (AGENTS.md "Required MATLAB Release"). Simscape
Multibody exposes no mass-matrix API, so the export must probe a model by forward
dynamics. That needs an open-tree model with joint torque inputs, position and velocity
targets, acceleration outputs and a cut-loop closure sensor. No golf model in the
repository has these, so the golf-model export is deferred and the golf-model
`CLOSED_LOOP_SNAPSHOT` capability stays **NONE**.

## Existing Capabilities and Evidence

Run on `deskcomputer` with `C:\Program Files\MATLAB\R2025b\bin\matlab.exe -batch`
(version string `25.2.0.3177638 (R2025b) Update 5`, Home licence banner). A structural
probe of `exploratory_gs3dx/models/GS3DX_Slim.slx` reported no error, and found:

- zero top-level inports, so there is nowhere to apply probe torques;
- 16 Simscape Multibody joint blocks, of which 3 are weld joints
  (`Club/Weld Joint`, `Grip/LeftHandOnClubForce`, `Grip/RightHandOnClubForce`), so the
  hand-club loop is closed inside the model rather than exposed as a cut;
- joint torque produced by internal Stateflow and MATLAB Function charts, not by inputs.

What was achieved instead, with real R2025b evidence, is the exporter, the versioned
format `simscape-closed-loop-snapshot/v1` and the loader, validated on a planar test rig
(`NSX_PlanarRig`, the NSX-00 planar golfer built as an open tree in Simscape Multibody).
Its export agrees with the analytic planar model to about 5e-14 relative. The rig is
**not** the golf model and is not acceptance evidence for it. See
`src/engines/Simscape_Multibody_Models/3D_Golf_Model/matlab/nsx_closed_loop_export/README.md`.

## Resources and Prerequisites

- Probe-capable open-tree variant of a GS3DX golf model, built and saved in MATLAB R2025b — **unbuilt**.
- R2025b host whose licence admits the variant's non-virtual block count — **untested**.
- Same-topology independent reference snapshot for comparison — **available from Pinocchio and OpenSim adapters once the topologies match**.
