# DV-12583: NSX-55 Live MATLAB R2025b Simscape Multibody Closed-Loop Snapshot Qualification

Source: [UpstreamDrift#12583](https://github.com/D-sorganization/UpstreamDrift/issues/12583) (Parent Epic: [UpstreamDrift#12593](https://github.com/D-sorganization/UpstreamDrift/issues/12593)). Status: **deferred**. Board: **pending**.
Disposition: **split**. Kind: external-review.

## Rationale and Expected Value

Full-body closed-loop null-space exploration (`NSX-55`) requires extracting the joint-space mass matrix $M(q)$, generalized bias vector $h(q, v)$, 6-DOF hand-to-club weld closure Jacobian $J_c(q)$, and velocity drift $\dot{J}_c(q, v)v$ from Simscape Multibody (`3D_Golf_Model`) under MATLAB **R2025b** (`25.2`) only (never R2026a, per repository MATLAB governance). While the MATLAB export script (`scripts/matlab/export_simscape_closed_loop_snapshot.m`), the Python snapshot loader (`src/shared/python/loop_nullspace/simscape_snapshot_loader.py`), and a checked-in R2025b reference export (`tests/unit/loop_nullspace/fixtures/simscape_r2025b_snapshot_sample.json`) are implemented and verified in CI, unattended CI runners and agent hosts do not hold a licensed live MATLAB R2025b + Simscape Multibody execution environment. Live trajectory-wide R2025b Simscape snapshot generation is therefore recorded as a deferred validation item while `SimscapeClosedLoopSnapshotAdapter` honestly reports `CapabilityLevel.NONE` when no pre-exported R2025b artifact is supplied.

## Deliverables Completed in Software

1. **MATLAB R2025b Export Script (`scripts/matlab/export_simscape_closed_loop_snapshot.m`):**
   - Enforces `strcmp(version('-release'), '2025b')` and explicitly rejects `R2026a` or any other MATLAB release.
   - Computes the 64-character SHA-256 digest of the `.slx` / `.mdl` model file and serializes `M`, `h`, `J_c`, `Jdot_v`, `S`, and `J_g` to JSON with schema `nsx-simscape-snapshot-v1`.
2. **Python Snapshot Loader and Capability-Gated Adapter (`src/shared/python/loop_nullspace/simscape_snapshot_loader.py`):**
   - `load_simscape_closed_loop_snapshot` validates `matlab_release == "R2025b"` and the 64-hex `model_sha256` checksum, converts closure rows via `to_canonical_closure(..., native=SIMSCAPE_CLOSURE_CONVENTION)`, and populates `ClosedLoopSnapshot`.
   - `SimscapeClosedLoopSnapshotAdapter` reports `CapabilityLevel.NONE` with `deferred_validation_id == "DV-12583"` when invoked without a verified R2025b snapshot export, and `CapabilityLevel.FULL` when backed by a checked-in R2025b export.

## Acceptance Criteria for Reactivation

- Execute `export_simscape_closed_loop_snapshot.m` on a licensed MATLAB **R2025b** (`version('-release') == '2025b'`) workstation with Simscape Multibody across the full 41-DOF `full_body_spec_hipcal_scaled.json` swing trajectory.
- Deposit the resulting R2025b snapshot bundle with verified `.slx` SHA-256 provenance and confirm Track N (`1e-6` scaled) and Track S (propagated `cond(A)` bound) cross-engine conformance against Pinocchio.
- Reject any artifact generated under MATLAB `R2026a` or synthetic/mocked MATLAB engines.
