# F02 Bounded Candidate Callback Handoff (#12021)

`motion_matching.bounded_candidate_search` owns the existing finite-budget SLSQP loop. `CandidateSearchProblem` freezes the initial and caller-admitted fallback plans, per-channel lower/upper bounds, and `evaluate(plan) -> (cost, signed_margins)`. `CandidateSearchPolicy` fixes evaluation, iteration, wall-time and feasibility limits. The result reports an immutable proposed plan or an explicit fallback reason, evaluated costs, call count, elapsed time and whether the fallback meets the supplied horizon margins. The result does not certify fallback physics or execute inputs.

`BoundedNMPC` still owns its torque-only Euclidean target, scenario rollouts, one-step safe fallback, stale observation policy and applied-command history. Its adapter calls the shared loop with the same SLSQP method and vector of hard margins. Vector-constraint preparation is included in the cooperative evaluation budget. The loop checks its own command bounds even if an evaluator omits them; it rejects missing, nonfinite or infeasible candidate predictions instead of manufacturing margins. `optimized` requires a successful solver, fresh finite evaluation, all margins within tolerance and improvement over the frozen fallback score.

For the native MyoSuite project task, the future adapter must map a small declared decision vector to exact ordered post-mapping commands, use `ProjectTaskNativeSearch.predict` for a provisional full-state rollout and a dimensionally scaled numerical objective, and use `promote` for guarded producer history and independent T01 replay. The adapter owns activation lag, contact/constraint policy, reference provenance and any physical acceptance. The shared kernel never imports the SDK or assumes a torque-only actuator map. Current extraction tests contain no capture fitting or muscular OpenSim qualification evidence.

Validation: the new callback tests exercise improvement, signed constraints, solver misreports, direct input bounds, failed/nonfinite native predictions, fallback validation, cancellation, warm start and evaluation exhaustion. Existing F02 native/torque tests remain the regression authority. Record actual CI and PR head in the PR handoff before publication.
