## Scope and Status

replay. The six-engine and ultimate native muscle-driven OpenSim acceptance

`replay_native_torque_bundle` in
`src/engines/physics_engines/mujoco/python/native_torque_replay.py`.

retained. Replay never receives the reference controller.

## Operational and Scientific Limits

Exclusive process ownership is required because MuJoCo callbacks are global.
Concurrent callback mutation is unsupported; no subprocess isolation is
claimed. The native function module and compiled model are hashed, but this
slice does not attest every transitive shared library or runtime option
outside the model. Raw source bytes and compiled identity are both checked.
Passive model forces and endogenous constraints/contact remain model-owned;
their physiological correctness is not certified.

The current scope excludes actuator filters, nonunit transmission and force
clamps. Initial explicit external loads, mocap drives, plugin state and active
gravity compensation fail admission. Control limits must already have been
applied before export. No private capture was loaded, no full-swing fit was
performed, and no new preview video is generated by these tests.
