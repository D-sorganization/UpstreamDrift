# Proximal-to-Distal Energy Transfer in the Golf Swing

Thesis-length scientific document investigating proximal-to-distal
(P→D) energy transfer in the golf swing: where it occurs, how it differs
between skilled and less-skilled players, and whether a player should
transfer energy distally **early** in the downswing or **retain it
proximally early and accelerate the transfer late** — with an **executed
modeling pathway** on UpstreamDrift's backend-neutral double-pendulum
golf model (92-program torque-timing sweep, pointwise ZTCF/ZVCF
drift-control decompositions, Robertson-Winter wrist-interface power
accounting).

Tracked by epics
[#8373](https://github.com/D-sorganization/UpstreamDrift/issues/8373)
(article) and
[#8383](https://github.com/D-sorganization/UpstreamDrift/issues/8383)
(thesis expansion + modeling pathway). Destined for eventual publication
in the `affinedrift` repository
([#8379](https://github.com/D-sorganization/UpstreamDrift/issues/8379)).

## Reproducing everything

```bash
# experiments (E1 sweep, E2 counterfactuals, E4 interface powers)
python3 -m scripts.research.proximal_distal_energy.run_experiments
# figures
python3 -m scripts.research.proximal_distal_energy.make_figures
# document
cd docs/research/proximal_distal_energy_transfer
quarto render proximal_distal_energy_transfer.qmd --to pdf
```

Requires Quarto + a LaTeX distribution (TeX Live with `lmodern`), and
Python 3.11+ with `numpy`, `matplotlib`, `pydantic`, `simpleeval`,
`pandas`. Experiments are deterministic (fixed-step RK4); provenance
(git SHA, parameters) is stamped into `data/*.json`.
