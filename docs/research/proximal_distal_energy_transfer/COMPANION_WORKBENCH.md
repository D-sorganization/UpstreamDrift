# Interactive Proximal–Distal Dynamics Workbench

The interactive workbench is an open-source companion to this research
resource. It lets readers change model parameters, replay force and moment
vectors, compare control histories, and inspect counterfactual outputs. The
workbench is exploratory: its output is generated by declared mathematical
models and is not a measurement of a golfer, a coaching prescription, or a
physiological inference.

## One Shared Implementation

The canonical implementation is maintained in the
[Tools pendulum simulator](https://github.com/D-sorganization/Tools/tree/1664d806df8a2c7b184d2d3fbcea93b714caaee5/src/pendulum_simulator).
Both the PyQt6 desktop interface and the React/Tauri interface consume the same
[experiment and glossary catalog](https://github.com/D-sorganization/Tools/blob/1664d806df8a2c7b184d2d3fbcea93b714caaee5/src/pendulum_simulator/src/double_pendulum_golf/resources/companion_catalog.json).
UpstreamDrift launches that provider and pins an immutable Tools revision in
`vendor/ud-tools`; it does not maintain another copy of the companion logic.

The shared catalog is a scientific contract. Every guided experiment declares
its purpose, hypothesis, observables, workflow, interpretation tips, falsifier,
and limitations. Run manifests also record the catalog version, model,
experiment, parameters, units, and `exploratory_model_output` evidence status.

The publication bundle and the pinned workbench now expose the qualified
`rotating_base_torso_velocity` tier through one source implementation. Its
seven-coordinate constrained model drives the registered 18-run catalog used by
the PyQt6 and React/Tauri reviewer surfaces. The catalog retains all five adverse
rows, both matching rules, the three torso-command programs, full traces, and
the declared scientific-promotion boundaries. The interfaces must not substitute
the existing fixed-hub proximal coordinate and call it anatomical torso velocity.

## Running the Desktop Interface

From a sibling checkout of `Tools`:

```bash
cd Tools/src/pendulum_simulator
python -m pip install -e .
python -m double_pendulum_golf
```

Open **Companion Guide** in the toolstrip. The guide can switch among the
double-pendulum, triple-pendulum, and bilateral golfer models. Searchable terms,
hover help, workflows, falsifiers, and limitations remain visible without
changing the simulation state.

UpstreamDrift's unified launcher resolves this same provider from the sibling
`Tools` checkout. No physics source is copied into the launcher.

## Running the React or Tauri Interface

```bash
cd Tools/src/pendulum_simulator/pendulum-web
npm install
npm run dev
# Or use the desktop wrapper:
npm run tauri dev
```

The React guide appears above the workbench and loads the same catalog packaged
with the Python application. The browser and desktop views therefore use the
same experiment identifiers, hypotheses, falsifiers, limitations, and glossary
definitions.

## Guided Experiments

| Experiment                                        | Model            | Primary Question                                                                  | Disconfirming Observation                                                                            |
| ------------------------------------------------- | ---------------- | --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Passive Transfer in a Two-Link Chain              | Double pendulum  | Can interaction dynamics accelerate the club without a simultaneous distal drive? | Removing the declared proximal motion and applied torques leaves the same distal acceleration.       |
| Distal-Torque Onset Comparison                    | Double pendulum  | How does wrist-command onset change late distal speed and work?                   | Ordering disappears under matched initial states and declared parameter sweeps.                      |
| Three-Link Cascade                                | Triple pendulum  | Does the transfer pattern persist with an intermediate segment?                   | The cascade is absent or reverses under the registered perturbations.                                |
| Two-Hand Force and Equivalent-Couple Mechanism    | Bilateral golfer | Can separated hand reactions create a net club moment?                            | Coincident or zero-moment-arm hands retain the same couple.                                          |
| Pointwise and Forward Zero-Torque Counterfactuals | Bilateral golfer | Which conclusions survive a forward torque-removal intervention?                  | Pointwise and forward counterfactuals contradict the proposed mechanism outside declared tolerances. |
| Parameter Robustness and Falsifiability Envelope  | All models       | Is a conclusion robust to geometry, inertia, damping, and timing?                 | A small plausible perturbation reverses the registered conclusion.                                   |

These experiments are demonstrations, not confirmations. A useful result may
support, weaken, or reject a proposed mechanism. Inspect forces, moments,
power, work, energy closure, timing, and sensitivity together; do not infer a
biological actuator from a generalized torque or a contact reaction.

## Relationship to the Reproducible Article Analyses

The workbench is optimized for exploration and explanation. The article's
registered numerical results remain controlled by the scripts and recorded
data in this repository. When a workbench observation motivates a scientific
claim, reproduce it as a scripted, deterministic study with:

1. a frozen hypothesis and falsifier;
2. declared initial states, parameters, units, and numerical tolerances;
3. matched-state controls and relevant negative controls;
4. convergence, sensitivity, and closure tests; and
5. a machine-readable result linked to the manuscript.

This boundary keeps interactive exploration useful without allowing an
unrecorded GUI state to become publication evidence.

## Current Limitations

- The double and triple pendulums are reduced planar mechanism models.
- The bilateral golfer model is not subject-specific anatomy or measured grip
  tissue.
- Force vectors depend on the declared frames, reference points, constraints,
  and sign conventions.
- ZTCF results depend on whether the intervention is pointwise or forward.
- Numerical agreement across interfaces is implementation evidence, not human
  validation.
- Human falsification still requires synchronized kinematics, bilateral hand
  wrenches, club motion, ground reactions, launch outcomes, and the frozen
  participant-level analysis protocol described in this resource.
