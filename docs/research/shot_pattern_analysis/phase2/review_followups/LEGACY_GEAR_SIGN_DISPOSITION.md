# Legacy Gear-Effect Sign Disposition

The research replacement does not repair the legacy public helper. `src/shared/python/physics/impact_model/utils.py::compute_gear_effect_spin` documents positive horizontal offset as toe but returns negative Z spin for a centered face normal along +X. The live `ImpactSolver.solve_pre_impact_state` adds that spin, and `SwingBallFlightPipeline` calls that solver. Its documented frame is X forward, Y left, Z up. The native Magnus direction is spin × velocity (`rust_core/upstream-physics/src/aerodynamics.rs`), so negative Z spin at positive X speed bends toward negative Y, rightward. Existing tests encode that sign while calling it draw.

This is a verified unresolved legacy sign inconsistency, not a dead-code or Tools-owned exception. The helper has no diff from the original study base. Issue #11973 acceptance describes replacing the research off-center path with a consistent two-body solver; that replacement alone does not close the legacy public-consumer defect. The parent is filing a separate issue and preparing a test-first isolated repair. No legacy or frozen source was changed by this review. This note records the pre-repair disposition; acceptance requires the separate patch and regression evidence.
