# Representative Vector Rendering Review

The completed original 7-iron social density family was viewed as PNG and independently rasterized PDF/SVG. The header, three pattern panels, axes, HDR contours, marginals, shared scale and footer are intact in both renderings. Exact source/render hashes and actual pixel dimensions are retained in `review.json` and `raw_evidence.zip`. This is one representative family, not full vector or publication acceptance.

The installed Sharp renderer produced nonlinear scaling for explicit point units in a small synthetic viewport probe: configured density 72/96/144 yielded 72/128/288 pixels from a 72-point width. Consequently, record actual dimensions and original physical aspect; do not compare images by assuming identical nominal density settings. Any comparison thumbnails must fit proportionally without cropping captions or stretching. Deliverable files were unchanged.
