This editable research reference describes an incomplete prototype for issue
15493, not the engineering design manual or an accepted swing. The model is
embedded; separately named assets and the runtime are represented by
caller-asserted hashes. The manifest hash must be retained independently.

The prototype admits finite scalar-coordinate arrays with strictly increasing
reference and recorded times, cubic clamped spline knots, and a declared
number of equally spaced zero-order holds per recorded integration step.
State and hold clocks are stored separately; the hold count divides the
substep count and closure projection, if selected, occurs once per step.
Array dimensions and model,
asset, runtime and payload identities are checked before use. Flight and
feasibility results must be unavailable. A recorded latched force can be
replayed, with its actual pre-force state observed at the integration split;
it does not establish an on-face root or certify first contact.

For each quantity $x$ the comparison reports the maximum absolute difference
and checks $|x_{\rm run}-x_{\rm recorded}| \le a_x+r_x|x_{\rm recorded}|$ at
all supplied samples. Recorded playback does not run dynamics. A restricted
MuJoCo runner uses fixed-gain feedback, cubic residuals, ideal clipping and
the existing held-input integrator; it rejects passive shaft
coordinates, external assets and unsupported policies. Its runtime digest
measures a declared subset of code and libraries, not the full environment.
The stored Git SHA is a caller assertion, not a verified clean checkout.
The stored ideal input is not measured post-actuator torque. Numerical
agreement is not proof of independent simulation, continuous-time agreement,
anatomical feasibility or contact. Explicit research-v2 and v3 migrations
accept only previously authenticated, supported no-impact data. Full asset embedding, production migrations,
complete controller and integrator policies and a qualified forward runner
are required before this prototype could become a solution bundle contract.
