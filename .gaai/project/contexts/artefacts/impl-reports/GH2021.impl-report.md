## Root Cause Fix Details

The divergence (CV > 1.0) stemmed from:

1. **Timestep mismatch**: Engines defaulted to dt=0.001 (MuJoCo XML), dt=0.002 (MyoSuite),
   dt=0.01 (PendulumPhysicsEngine.step docstring). The runner enforces `config.dt` on every
   `engine.step(dt=config.dt)` call, overriding internal defaults.

2. **Missing cross-engine runner**: No class existed to apply identical noise and reset state
   uniformly. The new `CrossEnginePerturbationRunner` resets each engine before each trial and
   uses the same per-trial noise seed for all engines.

3. **Additive noise was not implemented**: The existing `perturb_torque_coeffs` only operated
   on polynomial coefficient perturbations. The new `perturb_torque_profile()` applies additive
   zero-mean Gaussian noise to raw torque time-series.
