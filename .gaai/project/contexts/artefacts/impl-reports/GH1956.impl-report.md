# Implementation Report: GH1956 — Strict Lazy-Loading of Engine Dependencies in Dashboard Launchers

## Summary

Moved heavy physics engine imports from module-level to inside `main()` in three dashboard launcher files. Added 9 unit tests verifying the lazy-loading contract. All CI checks pass.

## Files Changed

| File                                       | Change                                                                  | AC  |
| ------------------------------------------ | ----------------------------------------------------------------------- | --- |
| `src/launchers/mujoco_dashboard.py`        | Removed top-level `MuJoCoPhysicsEngine` import; deferred to `main()`    | AC1 |
| `src/launchers/pinocchio_dashboard.py`     | Removed top-level `PinocchioPhysicsEngine` import; deferred to `main()` | AC1 |
| `src/launchers/drake_dashboard.py`         | Removed top-level `DrakePhysicsEngine` import; deferred to `main()`     | AC1 |
| `tests/unit/test_launcher_lazy_loading.py` | New: 9 unit tests for lazy-loading contract across all 3 dashboards     | AC2 |

## Acceptance Criteria Coverage

- **AC1 (GH1956 resolved):** Engine-specific imports are now only triggered when `main()` is called, not at module import time. Verified by test suite.
- **AC2 (All new code has tests / TDD):** 9 new tests covering: module importable with engine absent, engine attributes not accessed at import time, `main()` function is callable. All pass.
- **AC3 (ruff check passes):** `ruff check` → 0 violations on all 4 changed files.
- **AC4 (No new print() in src/):** Confirmed no `print()` calls in modified `src/` files.
- **AC5 (PR targeting staging):** Will be created by Orchestrator after QA PASS.

## Rules Applied

- **DRY:** No duplicated blocks. Each dashboard file follows the same minimal pattern.
- **DbC:** No new public functions with preconditions needed; the change is pure import deferral.
- **LOD:** No method chains. No violations.
- **TDD:** Tests written alongside implementation in the same commit.

## Known Limitations / Notes

- The `noqa: PLC0415` suppression comment was added to the deferred imports to handle any lint config that flags imports-outside-top-level. In practice `ruff check` passed without needing it in this environment — but it is harmless documentation of intent.
- `drake_dashboard.py` retains `from PyQt6.QtWidgets import QFileDialog` at module level: this is a GUI framework import, not a physics engine dep, and is intentionally kept at the top.
