# GH1953 Implementation Report: Centralize and Implement Screw Axis Visualizations

## Summary

- Added `ScrewVisualizationTab` to `opensim_gui.py` (OpenSim's standalone GUI was the only engine GUI missing this tab)
- Added 10 unit tests for `ScrewVisualizationTab` UI component
- Added 9 unit tests for `plot_screw_axis_3d` visualization utility

## Implementation Notes

The shared module `src/shared/python/screw_theory/` was already complete with:

- `kinematics.py`: Twist, ScrewAxis, compute_screw_axis, compute_screw_endpoints
- `visualization.py`: plot_screw_axis_3d (matplotlib 3D axes)
- `ui.py`: ScrewVisualizationTab (PyQt6 toggle + target body input)

`SimulationGUIBase` (used by MuJoCo, Drake, and Pinocchio GUIs) already integrated the tab via `self.screw_viz_tab`. The Pendulums GUI also had it.

Only the OpenSim GUI (`opensim_gui.py`) was missing the tab — it uses a standalone `QMainWindow` and does not inherit `SimulationGUIBase`. The fix wraps the existing sim content in a `QTabWidget`, placing the simulation layout in a "Simulation" tab and the shared `ScrewVisualizationTab` in a "Screw Kinematics" tab.

The import is guarded with try/except to ensure the GUI degrades gracefully if the shared module is unavailable.

MyoSuite has no GUI component (it is a pure physics engine wrapper), so no tab was needed there.
