# GH2036 Memory Delta

## Pattern Confirmed

**Stub pattern for mixin testing:** The pattern of creating a minimal `_Stub` class that inherits
from a mixin and provides only the attributes the mixin accesses (via `getattr` or direct) is
validated for `AngularMomentumMetricsMixin` and `EnergyMetricsMixin`. This is the same pattern
used in GH1949 for engine availability testing. The approach:
1. Create a local `_Stub(TheMixin)` class in the test module
2. Provide only the attributes the mixin's methods access (the minimal interface)
3. Test the mixin method directly through the stub instance

This avoids coupling tests to the full host class hierarchy and keeps tests fast and isolated.
