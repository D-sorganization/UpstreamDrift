# GH2021 Memory Delta

## New Pattern: Cross-Engine Timestep Normalisation

**Domain**: physics engine integration, cross-engine comparison
**Pattern**: When running cross-engine comparisons, always override internal engine dt
by passing `dt` explicitly to `engine.step(dt=config_dt)`. Never rely on engine defaults.

**Location**: `src/shared/python/pendulum_simulator/cross_engine_perturbation.py`

## New Module

`CrossEnginePerturbationRunner` provides a reusable runner for cross-engine perturbation
studies. Key design decisions:

- `CrossEngineSimConfig` defaults to `t_end=1.5, dt=0.01` per GH2021 diagnostics
- Same per-trial seed for all engines ensures identical noise
- Engine reset before each trial eliminates state accumulation

## New Function

`perturb_torque_profile(profile, noise_amplitude, noise_type="additive", seed)` in
`perturbation_analysis.py` — handles additive noise on raw torque time-series.
Distinct from existing `perturb_torque_coeffs` (polynomial coefficient perturbation).

## Root Cause Signal

Engine timestep defaults differ across the codebase:

- `PendulumPhysicsEngine.step()`: default 0.01 s
- MuJoCo DOUBLE_PENDULUM_XML: `DEFAULT_TIME_STEP = 0.001` s
- `MyoSuitePhysicsEngine._dt`: default 0.002 s

Any cross-engine comparison must normalise this. Document as a known gotcha in
CLAUDE.md under "Physics Engine Gotchas".
