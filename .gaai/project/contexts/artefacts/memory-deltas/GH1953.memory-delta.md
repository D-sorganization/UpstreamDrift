# GH1953 Memory Delta

## Pattern: Centralized Shared UI Widget Integration

**Context:** When adding a new shared UI widget (like `ScrewVisualizationTab`) across multiple
engine GUIs, the primary surface for integration is:

1. `SimulationGUIBase` — covers all engines that inherit it (MuJoCo, Drake, Pinocchio)
2. Standalone GUIs (like OpenSim's `QMainWindow`) need direct integration

**Decision:** For standalone GUIs not using `SimulationGUIBase`, wrap existing content in a
`QTabWidget` with the existing layout as the first tab and the shared widget as the second tab.
Import with try/except to ensure graceful degradation.

**Pattern for future shared UI tabs:**

```python
# Guarded import at module level
try:
    from src.shared.python.screw_theory.ui import ScrewVisualizationTab as _Widget
    _WIDGET_AVAILABLE = True
except ImportError:
    _Widget = None
    _WIDGET_AVAILABLE = False

# In init_ui:
self._tabs = QTabWidget()
sim_tab = QWidget()
# ... existing content on sim_tab ...
self._tabs.addTab(sim_tab, "Simulation")
if _WIDGET_AVAILABLE and _Widget is not None:
    self._extra_tab = _Widget()
    self._tabs.addTab(self._extra_tab, "Shared Feature")
layout.addWidget(self._tabs)
```

## Note

MyoSuite does not have a GUI — only a physics engine wrapper. No tab integration is applicable there.
