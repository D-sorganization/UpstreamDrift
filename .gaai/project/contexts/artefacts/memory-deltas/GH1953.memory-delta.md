# GH1953 Memory Delta

## Pattern: Centralized Shared UI Widget Integration

**Context:** When adding a new shared UI widget (like `ScrewVisualizationTab`) across multiple
engine GUIs, the primary surface for integration is:

1. `SimulationGUIBase` — covers all engines that inherit it (MuJoCo, Drake, Pinocchio)
2. Standalone GUIs (like OpenSim's `QMainWindow`) need direct integration

**Decision:** For standalone GUIs not using `SimulationGUIBase`, wrap existing content in a
`QTabWidget` with the existing layout as the first tab and the shared widget as the second tab.
Import with try/except to ensure graceful degradation.
