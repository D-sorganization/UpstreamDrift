# GH1949 Memory Delta

## New Patterns Worth Persisting

### Pattern: Headless-safe UI test pattern with skip_if_unavailable

When testing Qt widget classes in a headless environment:

- Apply `@skip_if_unavailable("pyqt6")` at class level (not per-test)
- Use `get_qapp()` from `gui_utils` in a class-scoped fixture
- This pattern avoids `QApplication` errors in CI without any monkeypatching

File: `tests/shared/python/screw_theory/test_ui.py`

### Pattern: Mock matplotlib 3D axes for visualization tests

When testing functions that accept `matplotlib.axes.Axes3D`:

- Use `MagicMock()` as the axes object — avoids display server, import, and backend issues
- Verify calls via `ax.plot.assert_called_once()`, `ax.quiver.assert_called_once()`, etc.
- This enables fully headless unit testing of visualization utilities

File: `tests/shared/python/screw_theory/test_visualization.py`

### Pattern: Isolate module-level cache in engine_availability tests

`engine_availability._engine_status_cache` is a module-level dict that persists across tests.
Use `patch.dict(ea._engine_status_cache, {}, clear=False)` combined with explicit `.pop()`
for the specific key under test to avoid cross-test state pollution.

File: `tests/shared/python/engine_core/test_engine_availability.py`
