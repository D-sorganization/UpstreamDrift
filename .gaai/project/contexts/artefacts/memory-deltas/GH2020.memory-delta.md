# GH2020 Memory Delta

## New Patterns Identified

### Cross-Engine Dashboard Pattern

A new launcher pattern was established: `cross_engine_dashboard.py` demonstrates
how to build a multi-engine comparison GUI that:

1. Accepts a `CrossEngineSimConfig` rather than a single engine class
2. Falls back to `_StubEngine` when real engines are unavailable
3. Exposes a `--no-gui` CLI mode for headless/CI use

This pattern may be worth documenting in `conventions.md` if similar multi-engine
dashboards are built in future.

### Stub Engine Pattern

`_StubEngine` establishes a pattern for graceful degradation in environments
where physics packages (MuJoCo, Drake, Pinocchio) are not installed. If similar
functionality is needed elsewhere, this pattern should be extracted to a shared
location rather than duplicated.

## No Architectural Decisions Required

No new architectural decisions emerged. The launcher follows existing project
conventions (lazy-loading, logging, ruff compliance).
