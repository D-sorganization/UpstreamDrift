# GH1957: Memory Delta

## Key Findings

1. **Examples namespace alignment**: The `examples/` directory is fully aligned with the current
   `src.shared.python` namespace as of 2026-03-19. No technical debt was found.

2. **Test coverage pattern**: Two `test_examples.py` files cover different subsets:

   - `tests/unit/test_examples.py` — covers `01_basic_simulation.py`, `02_parameter_sweeps.py` via
     `importlib` loading and mock injection
   - `tests/unit/examples/test_examples.py` — covers remaining 5 examples via `runpy.run_path`

3. **Mock strategy**: The `runpy.run_path` approach in `tests/unit/examples/test_examples.py` is
   the preferred pattern for testing scripts that have `if __name__ == "__main__":` guards, as it
   executes the script in the `__main__` context without requiring importable module structure.

4. **Heavy integration format issues**: `tests/heavy_integration/` contains 8 files that need
   `ruff format` but `ruff check` passes. These are pre-existing and out of scope for audit stories.

## Patterns Worth Persisting

- The dual-file test_examples pattern (importlib vs runpy) is established and working. Future
  examples should be added to `tests/unit/examples/test_examples.py` using the `run_example()`
  helper function.
