# GH2035: Memory Delta

## Notable Patterns

### Pattern: xfail vs skip for pending functionality

**What:** Use `@pytest.mark.xfail(strict=False, reason="...")` with `raise NotImplementedError()` for tests that represent pending but not-yet-implemented functionality. Do NOT use `pytest.skip(...)` for this purpose.
**Why:** `xfail` tests are visible in pytest reports as expected failures, making pending work discoverable. `skip` hides them entirely.
**Established in:** GH2035 delivery

### Pattern: pytestmark skipif for module-level guards

**What:** For entire-module environment guards, prefer `pytestmark = pytest.mark.skipif(condition, reason="...")` over `pytest.skip(..., allow_module_level=True)`.
**Why:** Declarative skipif is evaluated at collection time and clearly signals the skip condition without imperative side effects. `allow_module_level=True` is acceptable only when the condition depends on a conditional import that cannot be expressed declaratively.
**Established in:** GH2035 delivery

### Anti-pattern: exception-masking skips

**What:** `except Exception as e: pytest.skip(f"X test failed: {e}")` is an anti-pattern that hides real test failures.
**Why:** When the dependency IS installed, test failures should fail — not be silently skipped. The guard for "not installed" should be at the module/class level via `pytestmark` or a fixture that calls `pytest.skip` at the top.
**Established in:** GH2035 delivery (fixed in test_myosuite_muscles.py)
