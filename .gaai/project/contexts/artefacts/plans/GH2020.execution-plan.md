# GH2020 Execution Plan: Cross-Engine Perturbation Comparison Dashboard

## Summary

Create `src/launchers/cross_engine_dashboard.py` — a self-contained PyQt6 CLI + GUI
launcher that wraps `CrossEnginePerturbationRunner` and presents per-engine summary
statistics and CV charts via Matplotlib. Add tests in
`src/launchers/tests/test_cross_engine_dashboard.py`.

---

## Implementation Sequence

### Step 1 — Create `src/launchers/cross_engine_dashboard.py`

**File:** `src/launchers/cross_engine_dashboard.py`

Design decisions:

- Follow the existing lazy-loading pattern from `mujoco_dashboard.py` /
  `pinocchio_dashboard.py`: all heavy imports (PyQt6, Matplotlib, engine modules)
  deferred inside `main()` and widget constructors.
- GUI is a standalone `QMainWindow` (not embedded in the Unified Dashboard), because
  the cross-engine dashboard has its own data model (`CrossEngineSimConfig`) that does
  not map to the existing single-engine `launch_dashboard()` interface.
- CLI fallback: when `--no-gui` flag is passed (or PyQt6 is unavailable), run the
  comparison and print a text summary table to stdout via `logging`.
- No `print()` calls in `src/` — use `logging.info()`.

**Classes / functions to implement:**

1. `CrossEngineDashboardWindow(QMainWindow)` — main window

   - `_build_config_panel()` → `QGroupBox` with:
     - Engine checkboxes: mujoco, drake, pinocchio, pendulum (at minimum)
     - `n_trials` QSpinBox (1–500, default 10)
     - `amplitude` QDoubleSpinBox (0.0–5.0, default 0.1)
     - `mode` QComboBox ("additive")
     - `t_end` QDoubleSpinBox (0.1–10.0, default 1.5)
     - `dt` QDoubleSpinBox (0.001–0.1, default 0.01)
   - `_build_chart_panel()` → `QWidget` with `FigureCanvasQTAgg`
     - Bar chart: Robustness Score per engine (defined as `1 - cv`, clamped [0,1])
     - Bar chart: CV per metric (energy, speed, peak speed)
   - `run_comparison()` slot — triggered by "Run" button:
     - Build `CrossEngineSimConfig` from UI values
     - Instantiate `CrossEnginePerturbationRunner`
     - Register only the engines whose checkbox is checked and whose module is available
     - Generate a zero baseline torque profile (shape: `(n_steps, 1)`)
     - Call `runner.run_comparison()` and `runner.compute_cv_summary()`
     - Update charts via `_update_charts(results, cv_summary)`
   - `_update_charts(results, cv_summary)` — refresh Matplotlib figures in-place
   - `_build_engine_stub(name)` → returns a minimal `SteppableEngine` stub for
     engines whose physics package is not installed (graceful degradation)

2. `main()` — entry point
   - Parses CLI args: `--no-gui`, `--engines` (comma-separated), `--n-trials`,
     `--amplitude`, `--t-end`, `--dt`
   - If `--no-gui`: run headless comparison, log results, exit
   - Else: launch `QApplication` + `CrossEngineDashboardWindow`

### Step 2 — Create `src/launchers/tests/test_cross_engine_dashboard.py`

**Tests (all `unit` marker, headless_safe):**

1. `test_cross_engine_sim_config_defaults` — construct with defaults, assert fields
2. `test_cross_engine_sim_config_invalid` — pass invalid dt/t_end, assert ValueError
3. `test_cross_engine_dashboard_window_init` — instantiate window with mock PyQt6
   (use `pytest.importorskip("PyQt6")` or mock)
4. `test_run_comparison_no_gui` — call `main(["--no-gui", "--engines", "stub",
"--n-trials", "2"])` with a stub engine; assert exits 0 / logs results
5. `test_cv_summary_chart_data` — verify chart data keys include
   `cv_total_energy_final`, `cv_end_effector_speed_final`, `cv_peak_end_effector_speed`

## Edge Cases

| AC  | Edge case                    | Handling                                                                  |
| --- | ---------------------------- | ------------------------------------------------------------------------- |
| AC1 | Engine package not installed | Graceful skip + log warning (never crash)                                 |
| AC2 | No engines selected          | Show error dialog (GUI) or log error (CLI), do not call runner            |
| AC3 | n_trials=1                   | CV = 0.0 (single trial — std is 0); handled by existing runner            |
| AC4 | ruff violations              | Enforced by CI; use `# noqa: PLC0415` for deferred imports per convention |
