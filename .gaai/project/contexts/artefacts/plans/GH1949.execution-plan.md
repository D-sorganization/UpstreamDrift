# GH1949 Execution Plan: [Testing] 526 source modules have no corresponding test file

## Story Summary

526 out of 736 source modules lack a matching `test_<module>.py` file. The goal is to
meaningfully reduce this gap by adding well-targeted tests for high-value untested modules.
Given the scale of 526 untested modules, this Story delivers a focused initial reduction:
targeting the `screw_theory` and `engine_core/engine_availability` modules, which are
foundational shared utilities with zero dedicated test coverage on `staging`.

## Approach

Targeted unit tests for 3 key untested source modules:

1. `src/shared/python/screw_theory/ui.py` → `tests/shared/python/screw_theory/test_ui.py`
2. `src/shared/python/screw_theory/visualization.py` → `tests/shared/python/screw_theory/test_visualization.py`
3. `src/shared/python/engine_core/engine_availability.py` → `tests/shared/python/engine_core/test_engine_availability.py`

Approach rationale: No approach evaluation needed. Established convention: one test file per
source module in mirrored directory structure. Tests use `pytest.mark.unit`, mock heavy
dependencies, avoid display server requirements.

## Implementation Sequence

### Step 1: Add test_ui.py for ScrewVisualizationTab

- File: `tests/shared/python/screw_theory/test_ui.py`
- Tests: Instantiation, is_active(), get_target_body(), signal existence, widget interaction
- Guard: `@skip_if_unavailable("pyqt6")` class-level decorator (PyQt6 may not be in CI env)
- Marker: `pytestmark = pytest.mark.unit`
- Checkpoint: File passes `ruff check`, no print() calls

### Step 2: Add test_visualization.py for plot_screw_axis_3d

- File: `tests/shared/python/screw_theory/test_visualization.py`
- Tests: rotation screws call ax.plot and ax.quiver, label passing, pitch annotation,
  pure-translation screws skip pitch annotation, color forwarding, length scaling, edge cases
- Guard: Mock matplotlib axes (MagicMock) — headless-safe, no display server required
- Marker: `pytestmark = pytest.mark.unit`
- Checkpoint: File passes `ruff check`, no print() calls

### Step 3: Add test_engine_availability.py for engine_availability module

- File: `tests/shared/python/engine_core/test_engine_availability.py`
- Tests:
  - `is_engine_available` returns bool for known engine names
  - `get_engine_status` returns EngineStatus enum values
  - `get_engine_status` for composite aliases ("parquet", "qt", "c3d_any", "gym_any")
  - `require_engine` decorator skips on unavailable engine (via pytest.skip mock)
  - `skip_if_unavailable` returns a pytest mark
  - `get_available_engines()` and `get_unavailable_engines()` return lists of strings
  - `__getattr__` returns bool for `NUMPY_AVAILABLE` pattern
  - Cache invalidation does not break subsequent calls
- Guard: No external engine imports needed; tests stdlib + internal state
- Marker: `pytestmark = pytest.mark.unit`
- Checkpoint: File passes `ruff check`, no print() calls

## Edge Cases

- PyQt6 unavailable in CI: `test_ui.py` must be entirely guarded with `skip_if_unavailable`
- matplotlib not needed at test level: `test_visualization.py` uses MagicMock for axes
- `require_engine` decorator triggers `pytest.skip` internally — tests must catch this
- `_engine_status_cache` is module-level; tests must not leave state that affects other tests

## Test Checkpoints

After each file is written:

1. `python3 -m ruff check tests/shared/python/screw_theory/test_ui.py` → zero violations
2. `python3 -m ruff check tests/shared/python/screw_theory/test_visualization.py` → zero violations
3. `python3 -m ruff check tests/shared/python/engine_core/test_engine_availability.py` → zero violations
4. `python3 -m ruff format --check tests/shared/python/` → zero diffs

Final: `python3 -m pytest tests/shared/python/screw_theory/test_visualization.py tests/shared/python/engine_core/test_engine_availability.py -v -m unit` → all tests pass

## Risk Register

| Risk                                     | Likelihood | Mitigation                                        |
| ---------------------------------------- | ---------- | ------------------------------------------------- |
| PyQt6 not installed in CI                | Medium     | `skip_if_unavailable` decorator                   |
| test_ui.py requires display              | Medium     | `skip_if_unavailable("pyqt6")` guards whole class |
| `_engine_status_cache` state leak        | Low        | Use `unittest.mock.patch.dict` to isolate cache   |
| test_visualization.py imports kinematics | Low        | kinematics is pure Python, no engine deps         |

## Rollback Boundaries

- New test files only — no modifications to src/ code
- If any test file causes import errors in CI, it can be removed without breaking functionality
- Tests are marked `unit` — excluded from `not unit` test runs
