# GH2035: Execution Plan — Audit and Reduce pytest.skip Calls

## Summary

Current state: 447 `pytest.skip` calls across 153 test files.
The story asks to audit and reduce these, classifying as **environment-skip** vs **missing-test**.

## Classification Taxonomy

### Category A — Environment Guard (KEEP / CONVERT to skipif)

Skips that are legitimately protecting against unavailable external dependencies:

- `pytest.skip("X not installed")` / `"X not available"` / `"X not found"`
- `pytest.skip("headless environment")` / `"DLL load failed"`
- Module-level `allow_module_level=True` for optional engine modules
- **Action:** Convert inline `pytest.skip()` → `pytest.mark.skipif` at decorator level where possible for better documentation and discoverability.

### Category B — Exception-Masking (CONVERT to pytest.raises / assert)

Skips inside `except` blocks that mask test failures:

- `pytest.skip(f"X test failed: {e}")` — the test actually ran and hit an error
- `pytest.skip(f"X loading failed: {e}")` — distinguishes install-miss from test failure
- **Count:** ~68 occurrences
- **Action:** Convert to `pytest.raises` with the expected exception type, or let the exception propagate as a FAIL when the component is available. Guard with skipif at the top for the not-installed case.

### Category C — Pending/Follow-up (CONVERT to xfail)

Skips on incomplete functionality:

- `pytest.skip("implement in follow-up")`
- `pytest.skip("pending matching models")`
- `pytest.skip("pending implementation")`
- **Count:** ~11 occurrences
- **Action:** Convert to `@pytest.mark.xfail(strict=False, reason="...")` so the pending work is visible in test reports without causing a hard failure.

### Category D — Logic-Guard Skips (REVIEW)

Skips inside test logic that guard on runtime conditions:

- `pytest.skip("Need at least 2 engines installed for comparison")`
- `pytest.skip("Not enough engines completed simulation")`
- **Action:** Keep as-is (these are valid runtime environment checks), but annotate with a comment explaining the intent.

## Implementation Sequence

### Phase 1: Audit and categorize (analysis only)

1. Run a full enumeration scan and produce a classification report
2. Group by category A/B/C/D
3. Identify top-priority files for conversion

### Phase 2: Convert Category C (Pending → xfail)

Target files:

- `tests/unit/engines/mujoco/test_power_flow.py` (2 skips)
- `tests/unit/engines/mujoco/test_screw_kinematics.py` (2 skips)
- `tests/unit/engines/mujoco/test_drift_control.py` (1 skip)
- `tests/integration/test_contact_cross_engine.py` (1 skip: "Drake contact model testing - implementation pending")
- `tests/integration/test_myosuite_muscles.py` (2 skips: "pending" pattern)
- `tests/unit/test_myoconverter_integration.py` (3 skips: "pending implementation")

### Phase 3: Fix Exception-Masking skips in test_myosuite_muscles.py (Category B)

The file `tests/integration/test_myosuite_muscles.py` uses a pattern of skipping inside except blocks for every test method. These should be refactored:

- Guard at module/class top with `pytest.mark.skipif(myosuite_not_installed, ...)`
- Let actual test failures fail (remove `pytest.skip(f"X test failed: {e}")`)
- Similarly for `tests/heavy_integration/test_myosuite_muscles.py`

### Phase 4: Convert top-priority Category A module-level skips to skipif decorators

Files using `allow_module_level=True`:

- `tests/integration/test_engine_api_integration.py`
- `tests/benchmarks/test_dynamics_benchmarks.py`
- And 16 others

Convert pattern:

```python
# BEFORE (module-level imperative skip)
try:
    import some_module
except ImportError:
    pytest.skip("module not available", allow_module_level=True)

# AFTER (declarative skipif at module level)
import importlib
pytestmark = pytest.mark.skipif(
    importlib.util.find_spec("some_module") is None,
    reason="some_module not available"
)
```

### Phase 5: Verify with ruff and pytest

- `python3 -m ruff check .` on modified files
- `python3 -m ruff format --check .`
- `python3 -m pytest -n auto --timeout=60 -m "not live_simulation"` (confirm no regressions)
