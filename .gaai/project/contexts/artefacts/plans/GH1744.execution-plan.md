# GH1744 Execution Plan: Raise test coverage from 50% to 70%

## Story Summary

Raise overall test coverage from ~50% (full suite baseline) to 70%.
Current measurement from unit+shared tests: 41.6% (49,946 / 120,137 statements).
Target: 70% → requires ~34,149 additional covered statements.

This plan delivers focused, high-ROI unit tests for 9 pure-Python modules
with 0–37% current coverage. Each module was selected for:

- No GUI/widget/external engine runtime dependencies
- Pure Python + numpy/scipy logic (fully mockable)
- High statement count (coverage ROI)
- Existing import path stability

## Approach

Targeted unit tests covering the core logic paths in each module.
No src/ changes. All tests: `pytestmark = pytest.mark.unit`, `ruff check` compliant,
no `print()` in test files, `patch.dict` for any module-level caches.

Approach rationale: follows the established convention in GH1949 —
mirror `src/` paths under `tests/`, one test file per source module,
mock optional dependencies (CoolProp, cantera, pandas, openpyxl) at import level,
use `pytest.mark.unit` throughout.

## Implementation Sequence

### Step 1: `tests/unit/test_pendulum_simulator_physics.py`

Tests `PendulumParams`, `JointLimits`, `TorqueClamp`, `mass_matrix`, `mass_matrix_components`,
`coriolis_vector`, `gravity_vector`, `forward_kinematics`, `kinetic_energy`,
`potential_energy`, `total_energy`, `equations_of_motion`, `joint_velocities`.

Key test cases:

- `PendulumParams` instantiation with valid/invalid inputs (AssertionError on negatives)
- `JointLimits` instantiation with default and custom limits
- `mass_matrix` returns 2×2 symmetric positive-definite matrix
- `coriolis_vector` at zero velocity is zero
- `gravity_vector` at q=[0,0] points downward
- `forward_kinematics` returns dict with expected keys (x1, y1, x2, y2, xC, yC)
- Energy functions return floats (kinetic=0 at rest, potential correctly computed)
- `equations_of_motion` returns ndarray of correct shape

Mock: `_native_backend` via `patch.dict("sys.modules", ...)`

## Edge Cases

1. **pendulum_simulator/physics.py**: `native_backend` may attempt Rust import — mock it entirely
2. **club_data/loader.py**: Excel paths require pandas+openpyxl — test JSON fallback paths only
3. **conversion/service.py**: Module-level cache `_normalized_cache` must be reset between tests via `patch.dict`
4. **physics_validation.py**: Uses `model_generation.core.validation` imports — may need mocking if not installed
5. **state_manager.py**: Uses filesystem — all tests use `tmp_path` fixture
6. **wgs_reactor_calculator.py**: `DEFAULT_DATABASE_PATH` may not exist — use `data_file=None` in tests
7. **acid_gas_dewpoint_calculator.py**: Optional CoolProp/thermo — mock both to force simplified path
8. **steam_engine.py**: CoolProp/Cantera optional — existing fallback path is well-tested; extend with boundary cases
9. **data_processing/core.py**: pandas/scipy required — skip with `pytest.importorskip("pandas")`

## Test Checkpoints (After Each File)

1. `python3 -m ruff check tests/unit/test_{module}.py` → zero violations
2. `python3 -m ruff format --check tests/unit/test_{module}.py` → zero diffs
3. `python3 -m pytest tests/unit/test_{module}.py -v` → all tests pass
4. No `print()` in any new test file (use logging if needed)
