# GH1953 Execution Plan: Centralize and Implement Screw Axis Visualizations

## Situation Assessment

The shared `src/shared/python/screw_theory/` module already exists with:

- `kinematics.py` — Twist, ScrewAxis, compute_screw_axis, compute_screw_endpoints
- `visualization.py` — plot_screw_axis_3d
- `ui.py` — ScrewVisualizationTab (PyQt6 toggle/tab widget)

The `SimulationGUIBase` (used by MuJoCo, Drake, Pinocchio GUIs) already integrates `ScrewVisualizationTab`.
The Pendulums GUI (`src/shared/python/pendulum_simulator/gui/main_window.py`) also has the tab.
MuJoCo has `ScrewKinematicsAnalyzer` in `screw_kinematics.py`.

**Gaps identified:**

1. `opensim_gui.py` (standalone `QMainWindow`) lacks the Screw Kinematics tab
2. MyoSuite has no GUI — no tab needed
3. Tests for `ScrewVisualizationTab` (ui.py) are missing
4. Tests for `plot_screw_axis_3d` (visualization.py) are missing

## Implementation Steps

### Step 1: Add ScrewVisualizationTab to OpenSim GUI

**File:** `src/engines/physics_engines/opensim/python/opensim_gui.py`

- Add `QTabWidget` wrapping the existing content
- Add a "Screw Kinematics" tab using `ScrewVisualizationTab`
- Import is lazy/guarded (already has try/except pattern)

### Step 2: Add tests for ScrewVisualizationTab

**File:** `tests/shared/python/screw_theory/test_ui.py` (new)

- Tests must use `pytest-qt` or mock PyQt6 — check availability
- Test `is_active()` returns False by default
- Test `get_target_body()` returns empty string by default
- Test widget can be instantiated (headless-safe with `@pytest.mark.headless_safe`)

### Step 3: Add tests for plot_screw_axis_3d

**File:** `tests/shared/python/screw_theory/test_visualization.py` (new)

- Test `plot_screw_axis_3d` calls expected matplotlib ax methods
- Uses mock axes (no display required)
- Test singular and general cases

### Step 4: Verify ruff check passes

Run `python3 -m ruff check` on all modified/new files.
