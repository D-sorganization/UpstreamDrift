# GH2020: Feature: Cross-Engine Perturbation Comparison Dashboard (GUI/CLI)

**Source:** D-sorganization/UpstreamDrift#2020

## Description

## Description

The `CrossEnginePerturbationRunner` successfully orchestrates multi-engine analysis but currently lacks a dedicated graphical interactive dashboard or official CLI entrypoint in the `src/launchers/` directory.

## Objective

- Develop `cross_engine_dashboard.py` in `src/launchers/`.
- Provide a PyQt6 interface to configure engines (`mujoco`, `drake`, `pinocchio`, etc.) and perturbation configurations (`n_trials`, `amplitude`, `mode`).
- Parse the resulting `CrossEngineReport` into visual components (e.g. Matplotlib charts comparing `Robustness Score` and `CV`).

## Parity Expansion

Expanding upon the recently formalized `PerturbationAnalyzer` protocol, a centralized cross-engine dashboard is the final step to evaluating engine drift at an ecosystem level.
