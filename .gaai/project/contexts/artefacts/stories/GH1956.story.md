# GH1956: Consolidate GUI Interfaces and ensure strict lazy-loading of engine dependencies

**Source:** D-sorganization/UpstreamDrift#1956

## Description

**Objective:** Consolidate GUI Interfaces and ensure strict lazy-loading of engine dependencies.

As we add more capabilities to the UpstreamDrift launcher (e.g., Pendulums, Humanoid Golf, diverse robot planners), the UI framework might accidentally import heavy dependencies (like Mujoco or Drake) just to render a UI tab.

**Tasks:**

1. Refactor the launcher UI so that engine-specific Python packages are ONLY imported when that specific tab/module is activated.
2. Ensure UI components are decoupled from their underlying physics engines to maintain a responsive and lightweight startup time.

## Acceptance Criteria

1. The issue described in #1956 is resolved
