# GH2021: Bug: Severe Divergence in Cross-Engine Perturbation Consistency (CV > 1.0)

**Source:** D-sorganization/UpstreamDrift#2021

## Description

## Description
An implicit test utilizing `CrossEnginePerturbationRunner` with identical `additive` noise on a standard torque profile revealed massive inconsistencies in final simulation states across `myosuite`, `mujoco`, and the baseline `pendulum` engines. 

## Diagnostics
Current metrics output highly divergent states:
- `total_energy_final`: CV = 1.50 (Spread = 573.17)
- `end_effector_speed_final`: CV = 1.36 (Spread = 33.42)
- `peak_end_effector_speed`: CV = 1.23
- `trajectory_rmse`: CV = 1.21

## Objective
- Audit and standardize multi-engine default initializations. Ensure integration timestamps (`t_end=1.5`, `dt=0.01`) and standard pendulum masses/lengths are perfectly mirrored between engine URDFs/XMLs.
- Identify whether specific engines (e.g., `myosuite`) handle joint limits or contact dissipation differently, leading to severe relative energy divergence under noisy conditions.
