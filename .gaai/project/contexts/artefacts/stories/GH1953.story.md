# GH1953: Centralize and implement Screw Axis visualizations across all engines

**Source:** D-sorganization/UpstreamDrift#1953

## Description

Currently, the screw axis visualizations are fragmented. We have `mujoco_humanoid_golf/screw_kinematics.py` and `drake/python/src/screw_theory` but this logic needs to be a unified, shared module.

Additionally, we lack screw axis visualizations entirely in Pendulums, OpenSim, MyoSuite, and Pinocchio.

We need to:

1. Extract existing screw axis computation and visualization logic into a shared module (e.g., `src.shared.python.screw_theory`).
2. Add a uniform toggle/tab to view these visualizations across Mujoco, Pendulums, Drake, OpenSim, MyoSuite, and Pinocchio.
3. Establish feature parity so any reference frame moving through space can clearly render its instantaneous screw axis.

## Acceptance Criteria

1. The issue described in #1953 is resolved
2. All new code has tests (TDD)
3. `ruff check` passes on modified files
4. No new `print()` calls in `src/`
5. PR created targeting `staging` branch with clear description
